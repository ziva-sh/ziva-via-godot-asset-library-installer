# Ziva Installer

This folder is an installer for Ziva (https://ziva.sh), an AI agent that runs inside the Godot editor, made by Zivash Inc. Click `Install Ziva AI Agent` in its dock to download Ziva into `addons/ziva_agent`, then restart the editor.

## What is Ziva?

Ziva reads your project files, inspects the scene tree, checks editor errors, edits scenes and scripts, runs the game to check its work and fixes the errors it finds. Plans and prices: https://ziva.sh/pricing

## Privacy

Your project code is sent to the AI model you choose; each model in the picker shows a privacy badge. Ziva does not use your private code to train models. Details: https://ziva.sh/privacy

## Need help?

- Discord: https://ziva.sh/discord
- Docs: https://ziva.sh/docs
- Report a bug or request a feature: https://github.com/ziva-sh/ziva-agent-plugin-godot/issues

## Uninstall

Close Godot, then delete the `addons/ziva_agent` and `addons/ziva_installer` folders. Reopen Godot afterwards.
